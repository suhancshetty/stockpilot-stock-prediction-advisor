# Project Visual Assets

This directory stores visual assets, architecture diagrams, and application screenshots for the StockPilot repository and documentation.

## Suggested Screenshot Filenames
When capturing screenshots from the running Streamlit dashboard (`streamlit run app.py`), save the cropped or full-window PNG images here:

- `dashboard_overview.png`: Top view of the dark trading terminal dashboard.
- `prediction_summary.png`: Prediction metric cards and directional forecast banner.
- `model_comparison.png`: MAE, RMSE, and MAPE regression comparison table.
- `technical_indicators.png`: 20-day MA, 50-day MA, RSI (14), and MACD metrics with BUY/SELL/HOLD signal.
- `risk_analytics.png`: Annualized volatility, maximum drawdown, and average daily return cards.
- `investment_simulator.png`: Virtual investment simulator with multi-currency conversion.
- `actual_vs_predicted_chart.png`: Interactive line chart of test observations vs machine learning predictions.

For detailed capture guidelines, refer to [docs/SCREENSHOTS.md](../docs/SCREENSHOTS.md).
